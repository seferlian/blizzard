# Contributing to SnowBlizzard

Спасибо за интерес к проекту! Пожалуйста, прочитайте эти правила перед тем, как предлагать изменения.

## 📜 Лицензия и авторские права

Проект распространяется под лицензией **PolyForm Shield License 1.0.0** (см. файл `LICENSE`). Это означает:
- Вы можете просматривать, изменять и распространять код.
- Вы **не можете** использовать код для создания продуктов, конкурирующих с SnowBlizzard.
- Вы **обязаны** сохранять уведомление об авторстве (`Required Notice`) в любых копиях или производных работах.

## 🤝 Как предложить изменения (Pull Request)

1.  Сделайте форк репозитория.
2.  Создайте ветку для вашей функции или исправления.
3.  Внесите изменения.
4.  Отправьте Pull Request с подробным описанием того, что вы изменили и зачем.

**Важно:** Отправляя Pull Request, вы автоматически соглашаетесь с тем, что ваши изменения будут распространяться под текущей лицензией проекта (PolyForm Shield). Вы также подтверждаете, что у вас есть право на эти изменения.

## 🚫 Что не приветствуется

- Прямое копирование кода в другие проекты без указания авторства (это нарушение лицензии).
- Создание форков, которые позиционируются как «замена» или «конкурент» SnowBlizzard.
- Изменения, которые ломают существующую функциональность без веской причины.

## 💬 Вопросы

Если у вас есть вопросы по лицензии или использованию кода, свяжитесь со мной через GitHub Issues или напрямую.
